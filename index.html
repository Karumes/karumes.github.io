Quick Start Guide (Windows)

1
Run the Installer

Double-click KarumesClock Setup 1.0.0.exe to install the app. The clock dashboard will open automatically.

2
Customize Options

Click on your favorite clock, open Settings to change colors or sizes, and click Apply to save your customization.

3
Register as Screensaver

Right-click register-screensaver.bat and select "Run as administrator". Confirm system prompts and click "OK" in the Windows Screensaver Settings window.

Quick Start Guide (macOS)

1
Install the App

Open KarumesClock-1.0.0-arm64.dmg and drag the application to your Applications folder. Launch the app once to initialize files.

2
Customize Options

Select your preferred clock on the dashboard, modify colors or sizes via Settings, and click Apply to save your preferences.

3
Register as Screensaver

Extract KarumesClockSaver.zip, double-click the .saver file to install, and select KarumesClockSaver in your macOS Screen Saver Settings.
